## The Big Idea: Three Layers of Context

The Bridge v1.0 solves the **Person Layer** — who you are.
But there are two more layers that every Human-AI team needs:

| Layer | Question It Answers | Status |
| :--- | :--- | :--- |
| 🔮 **Person Bridge** | "Who is this human?" | ✅ Built — Soul File |
| 📁 **Project Bridge** | "What are we building?" | 🔜 v2.0 |
| ⚡ **Session Bridge** | "What just happened?" | 🟡 Partial — Session Log |

A complete Bridge gives every AI session the full picture:
*"You are talking to Ron. He is building The Compass. Last session he fixed the startup script."*

## 📁 Layer 2: Project Bridge (v2.0 — The Big Expansion)

This is what developers call `.cursorrules`, `CLAUDE.md`, or a "Memory Bank."
The Bridge makes it beautiful and accessible for *everyone* — not just coders.

### What it captures:
| File | Contents |
| :--- | :--- |
| `project_brief.md` | What are we building? What's the goal? What does success look like? |
| `tech_context.md` | What technology are we using? (Stack, tools, preferences) |
| `active_context.md` | What are we working on *right now*? What's in progress? |
| `patterns.md` | What decisions have we already made? What rules do we follow? |
| `progress.md` | What's done? What's next? What's blocked? |

### Who needs this:
- **Engineers**: Replace their manual `.cursorrules` files with a guided, beautiful interface
- **Vibe Coders** (Ron): Auto-generate this from a conversation — no manual file writing
- **Writers**: Track chapters, themes, character notes across AI sessions  
- **Musicians**: Track song arrangements, production notes, sessions
- **Any creator**: Anyone building something complex over time

### The key insight:
> The Project Bridge is a *living document.* It updates as the project grows.
> The Soul File is a *stable foundation.* It changes slowly as you grow.

---

## ⚡ Layer 3: Session Bridge (v2.0 — Enhancement)

The Session Log in v1.0 is a start. v2.0 goes deeper:

- **Auto-summarize**: After a session, paste the conversation and The Bridge extracts the key decisions automatically
- **Decision Log**: What did we decide today? Why?
- **Blocker Tracker**: What's stuck? What does the AI need to know to unblock it?
- **Momentum File**: The 3 most important things to pick up next session

## 🛠️ Feature Ideas for Bridge v2.0

### For Vibe Coders & Creatives
- **Project Wizard**: Guided form to build a full Project Bridge in 15 minutes
- **One-click export**: Generates a complete `.bridge/` folder with all context files
- **"What does my AI need right now?"** — A 60-second check-in form before each session

### For Engineers & Developers
- **Import from existing files**: Reads your `README.md`, `package.json`, or `.cursorrules` and converts them to Bridge format
- **Git-aware context**: Reads recent commits to auto-update `active_context.md`
- **Tech Stack Profiles**: Pre-filled templates for React/Next.js, Python, etc.

### For Teams
- **Team Soul File**: Shared context that multiple collaborators contribute to
- **Role Profiles**: "I'm the designer" vs "I'm the backend lead" — different context blocks for different roles

### For Everyone
- **Community Templates**: Browse and download Bridge templates for common use cases (podcast production, novel writing, app development, music production)
- **"Bridge Handshake"**: A standardized format any AI can recognize — becomes an open standard
- **The Bridge Network**: Share your Bridge templates with the community (privacy-optional)
